## 真实缺点和容易踩的坑

永久授权不等于永久免费升级。官方在授权说明里写的是"更新覆盖到某个日期"，2024 年 11 月 SmartGit 24.1 发布时，官方提示的是授权覆盖到 2024-11-06 及之后的用户会自动升级。换句话说，买断买的是当时那个版本加一段升级窗口，窗口过后新版本用不了，老版本可以继续用。冲着"一次付费终身更新"去的人，会失望。

订阅版需要客户端能上网。官方明确要求保证 SmartGit 可以访问互联网，好让它自动下载下一期的授权文件。放在内网隔离环境或者长期离线的机器上，续期会卡住，采购前先跟 IT 确认。

企业自建 Git 服务的集成不在免费档里，这条前面提过，但很容易被忽略：用公司自建 GitLab 的开发者申请了免费授权，会发现对接功能是灰的。

官方支持只覆盖工作日 9:00 到 17:00（CET/CEST），换成北京时间大约是下午四点到午夜，夏令时会提前一小时。赶上线的时候提工单，别指望立刻有人回。

税费和发票要在付款前问清楚。官网走 Cleverbridge 结算，部分地区的订单会加销售税，美国的免税机构还有单独的申报流程；国内渠道能不能开票、开什么类型的票，商品页或客服那边确认后再付。

还有一个我查不到明文的问题：授权按"用户数"卖，一个用户能不能同时装在办公机和家里那台，官方页面没有写清楚。多设备办公的人，下单前问一句，比事后争论省事。

关于第三方评价，我没找到足够可信、专门针对 SmartGit 授权的独立评分数据，所以这一节只写能从官方条款里逐条核对的东西，不替它编用户口碑。

## 常见问题

**数码荔枝卖的 SmartGit 是正版吗？**
判断标准只有一条：能不能拿到 Syntevo 签发的授权文件，并在客户端里正常激活、显示授权信息。下单前问清楚是订阅还是永久、包含几个用户，收到后当场激活验证。

**订阅到期后会怎样？**
官方只写明订阅期内可获得支持并使用最新版本，到期后的具体限制没有在页面上展开。手上有旧安装包的通常还能继续用，但拿不到新版本。续费前问客服确认。

**学生免费授权能用来接项目吗？**
不能。非商业授权限定个人非商业用途、开源项目、公立院校教学科研和公益机构。拿去给客户做外包，属于超范围使用。

**一个人几台电脑能用？**
官方按用户数计价，页面没有明确写设备数量限制。多设备办公的人需要在下单前向渠道确认。

**能开发票吗，价格含税吗？**
官网结算走 Cleverbridge，部分地区的订单会加销售税；国内渠道的含税情况和发票类型，在商品页或客服处确认。
